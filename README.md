# specbook — 施工規範編修工具

**specbook = spec（施工規範）+ book（規範書）。** 這個目錄是一個工具，用來把工程會的
「公共工程施工綱要規範」編修成一件工程可以直接放進契約的施工規範書。

狀態：設計中（2026-09-26）。還沒有程式碼。

## 解決什麼問題

工程會公開 314 章施工綱要規範，每章都是參考範本，不能直接照抄。實際編一份規範時，
費工的地方是：

1. **挑章**：這件工程要收哪些章。預算書的工項碼前 5 碼就是章碼，可以從預算書直接帶出來，
   也能順便找出對不上的碼，例如不存在的章、Z 開頭的暫用碼。
2. **填方括號**：規範內共有 14,625 組 `[選項][　　]`，每章平均 47 組。每一組都要選一個選項
   或自己填寫，完成的規範不能留下空的方括號。
3. **檢查**：章碼、章名、編號不能改；每章要標出參照的版次；每章結尾要有〈本章結束〉。
4. **產出**：輸出成 DOCX，附目錄。

## 和其他目錄的關係

```
/Volumes/AI-Model/ACKB        營建法規知識庫。負責收集工程會規範原檔，
                              並產出本工具用的「章節資料包」（JSON）。
        │ 章節資料包
        ▼
/Volumes/AI-Model/specbook    本目錄。
  engine/                     引擎：純 JavaScript 模組，不依賴任何套件。
                              工項碼 → 章節、記錄方括號怎麼填、檢查、整理輸出內容。
  plugin/                     Studio5 plugin（使用者操作的畫面，部署到 m2）。
        │ 將來可能共用引擎
        ▼
/Volumes/AI-Model/Quotation   工程報價系統。它的前端是 Vue + TypeScript，
                              需要時可以直接 import 同一個引擎（目前不做）。
```

- 使用者只需要開 Studio，不需要安裝 ACKB 或 Quotation。
- 引擎寫成純 JavaScript，是為了讓 Studio 和 Quotation 的前端都能直接使用同一套，
  不需要編譯步驟，也不需要 WASM。
- 章節資料包由 ACKB 產出，因為解析工程會的 doc/odt 原檔、判斷版次這些工作，
  ACKB 已經有現成的收集和轉檔程式。
